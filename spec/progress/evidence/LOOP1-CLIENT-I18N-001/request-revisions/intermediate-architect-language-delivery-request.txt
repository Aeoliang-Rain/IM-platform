继续当前任务，将 Web、Desktop、Mobile 三端的 i18n 实现目标统一调整为：

“仅内置简体中文（zh-CN），作为默认语言与完整兜底语言；英语、日语等其他语言以独立语言包分发，由用户自主选择下载、保留和启用。”

本指令是 architect 对本次语言资源交付方式及默认语言的明确调整。先按 AGENTS.md 读取当前权威规范、任务和检查点，同步此次调整涉及的架构说明、任务目标与验收标准，再完成三端实现。沿用各端当前已批准的技术栈和工作流，不得只修改 Resources.kt 所属客户端。

一、重构三端语言资源
1. 将翻译正文从 Kotlin、TypeScript 等业务源码中的硬编码字典迁移为独立的语言资源数据文件。三端统一资源格式、翻译 key、占位符语义与兼容规则，维护统一权威来源，各端通过适配器加载。
2. 三端仅随客户端交付完整的 zh-CN 资源。首次启动默认中文；语言配置无效、所选语言包缺失或不可用时回退中文；目标语言缺少个别 key 时逐项回退中文。
3. 英语和日语资源保留为独立可发布语言包，不得继续进入 Desktop/Mobile 安装包、Web 首屏资源或自动预缓存集合。允许语言名称等目录元数据内置，但不得以隐藏资源、备用字典等形式继续捆绑完整翻译正文。
4. 更新所有原有英文默认值与英文兜底逻辑。对旧语言偏好做迁移：已选语言没有有效本地语言包时使用中文并提示用户下载，不得为恢复旧偏好擅自下载。
5. 构建测试必须保证中文兜底资源覆盖当前三端使用的全部翻译 key，并检查各语言包的占位符一致性。

二、实现真实的按需分发与安装
1. 分离“可下载语言目录”与“语言包正文”。目录提供语言代码、原生名称、显示顺序、资源版本、格式版本、兼容信息、下载地址、大小和校验摘要。
2. 优先复用项目现有静态资源托管与发布链路，落实真实可用的目录及语言包下载地址，并补充必要的构建、发布和部署配置。
3. 语言包仅包含翻译数据。下载使用项目控制的 HTTPS 来源，并验证大小限制、摘要、格式、语言代码与兼容性。
4. 下载内容先暂存，校验通过且本地保存成功后，才提交为“已安装”。失败时清理本次无效内容，保留原有有效语言包和当前语言。
5. 可用语言由目录和本地安装记录驱动，不能继续仅依赖源码中写死的三语言白名单；加载与校验逻辑应区分“目录中可下载”和“本地已安装”。
6. 必须形成“独立发布资源 → 用户发起下载 → 校验 → 本地安装 → 加载”的真实链路，不能用从安装包复制文件、模拟进度或全部资源提前加载来代替下载。发布条件缺失时明确记录阻塞，不得将下载闭环标记完成。

三、调整 Settings 的语言管理界面
1. 保留 “Language / 语言 / 言語” 入口，以及既定的 English → 简体中文 → 日本語 固定顺序和滚动列表形式；默认中文不代表擅自调整展示顺序。
2. 区分语言包的安装状态与当前启用状态，展示内置、未下载、下载中、已安装、下载失败等必要信息。
3. 支持下载、启用、删除已下载语言包。下载与启用分离：用户可以下载多个语言包而仅启用其中一个；只有明确选择“下载并使用”时，才在安装成功后自动切换。
4. 内置中文不可删除。删除正在使用的外部语言包时，先安全切回中文，再删除该包。
5. 下载失败、校验失败或保存失败时提供可理解的提示和重试入口，保持原语言正常工作。持久化失败不得显示为“已安装”。
6. 切换语言不改变主题、字号、间距、登录状态、聊天内容及消息处理状态。

四、完成三端加载与持久化适配
1. 各端持久化已安装语言包、安装元数据和用户语言选择。重新启动或刷新后优先加载有效本地资源，不因启动而自动下载其他语言包。
2. Desktop/Mobile 使用当前架构允许的应用私有存储；Web 使用浏览器持久化能力保存语言资源和偏好。同步修正相关存储边界说明及界面文案，该调整只涉及语言资源与偏好。
3. 本地资源被清除、损坏或变得不兼容时，核对并修正安装状态，安全回退中文，不得保留“显示已安装但实际不可用”的状态。
4. 翻译状态应同时反映启用语言和资源版本变化，确保语言切换或同语言资源替换后，界面实际刷新，而非仅修改设置值。
5. 已安装语言在应用或页面已加载的情况下应能断网切换。覆盖各端已有的应用自有界面文案，包括适用的窗口、托盘、通知和错误提示。
6. 保留现有业务行为与各端数据边界，仅修改本次语言资源、管理界面、分发配置及必要的规范和测试。

五、按三端分别验收并留证
必须覆盖：
- 全新安装或清空站点数据后默认显示中文，无需下载即可使用中文界面。
- 初始客户端交付内容不包含英语、日语翻译正文；首次运行和打开语言设置不会自动请求这些正文。
- 只下载英语时，日语仍未安装且没有被请求；允许同时安装英语、日语。
- 单纯下载不改变当前语言；明确启用后界面正确刷新。
- 已安装语言可在断网状态下切换；重启或刷新后能恢复有效本地资源与语言选择。
- 下载中断、摘要错误、格式错误、不兼容、持久化失败时，原语言仍可用，不产生虚假的已安装状态。
- 删除当前语言包后正确回退中文；中文不可删除；清除缓存后安装状态能够自我修正。
- 旧语言偏好迁移、缺词中文回退、占位符替换和资源版本变化均有测试覆盖。
- 现有登录、聊天、消息同步及外观设置没有回归。
